Privacidad y Datos

Tu perfil usa datos de cuenta, tests y señales locales para mostrar tu evolución vocacional con claridad.

La app orienta, no decide por ti.

Los resultados son una guía para explorar carreras, universidades y próximos pasos. No son una sentencia definitiva ni reemplazan a un orientador vocacional.

Datos de cuenta: nombre, foto, contraseña y preferencias siguen usando la API actual.
Datos vocacionales: tests, calibraciones, simuladores y feedback local se usan para calcular confianza y evolución del perfil.
Ubicación: se usa para buscar universidades cercanas y calcular distancia. No define tu perfil vocacional.
IA: puede explicar recomendaciones, pero no calcula sola el match ni debe tomarse como decisión final.
Fallback local: el camino STEAM puede usar datos locales temporales mientras no exista endpoint dedicado.
Información insuficiente: cuando falten datos reales, la app debe mostrarlo como “datos insuficientes”, local o mock.
Control de datos: no hay flujo de eliminación definitiva de cuenta conectado en esta pantalla todavía.
